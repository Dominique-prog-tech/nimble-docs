# Formules d'appel

Les **formules d'appel** sont celles que vous pouvez attribuer à une personne de contact : monsieur, madame … Cette liste alimente le champ **Formule d'appel** sur la fiche de contact.

## Ouvrir l'écran

1. Cliquez sur **Administration** en bas de la barre latérale.
2. Dans le groupe **Relations**, cliquez sur la tuile **Formules d'appel**.

## La liste

| Colonne | Signification |
|---|---|
| **Ordre** | Détermine l'ordre dans la liste de choix (bas = en haut) |
| **Code** | Code court et unique |
| **Nom (NL)** | Nom en néerlandais |
| **Nom (FR)** | Nom en français |

Double-cliquez sur une ligne pour la modifier, ou cliquez sur **Nouvelle valeur**. **Exporter** vous permet de récupérer la liste dans un fichier.

## Créer ou modifier une formule d'appel

Une fenêtre **Nouvelle valeur** ou **Modifier** s'ouvre.

1. L'**Ordre** est proposé automatiquement (le plus élevé + 10) ; modifiez-le pour déplacer la valeur.
2. Saisissez le **Code** — obligatoire et unique. Si le code existe déjà, même pour une valeur dans la [corbeille](recycle-bin.md), Nimble indique à quelle valeur il appartient.
3. Saisissez le nom dans la **langue de base de votre entreprise** — obligatoire. L'autre langue porte la mention **facultatif**.
4. Cliquez sur **Enregistrer**, ou sur **Annuler** pour fermer la fenêtre sans enregistrer.

## Supprimer

Ouvrez la formule d'appel et cliquez sur **Supprimer** à droite dans la fenêtre. Après confirmation, elle va dans la [corbeille](recycle-bin.md) ; les personnes de contact qui l'utilisent la conservent. Vous pouvez la récupérer via la corbeille.

## Erreurs fréquentes

!!! warning
    - **Oublier le nom français** — les utilisateurs francophones voient alors le nom dans la langue de base.
    - **Supprimer des formules d'appel encore utilisées** — les personnes de contact existantes la conservent, mais les nouvelles ne peuvent plus la choisir.
